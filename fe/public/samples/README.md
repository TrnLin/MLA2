# Sample product photos

These local product photos are from the DummyJSON demo catalogue:
https://dummyjson.com/

`sources.json` records each product's original title, category, image URL, and
local filename. The numeric filenames are DummyJSON product IDs, not assignment
dataset IDs.

The sample picker shows a T-shirt (84), Watch (93), Bag (173), and Dress (177),
in that order. Selecting a sample sends its original image to the local model
server for predictions and visual search.

These photos are query samples, not training data, evaluation data, or the
Task 4 search gallery. Their display names do not set the model predictions.
