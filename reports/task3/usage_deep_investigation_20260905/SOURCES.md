# Primary sources checked on 5 September 2026

These sources support the research plan. They do not establish a performance gain on the teacher data. No external image dataset was downloaded in this investigation.

| Source | Verified facts relevant to this task | Access / licence / remaining limit |
|---|---|---|
| [Assignment PDF](<../../../docs/COSC2753_2026B_Assignment 2.pdf>), pp. 4 and 6 | Additional collection is allowed; evaluator access is required; submitted learned systems must be trained from scratch. | Read the full extracted spec and inspected rendered pages. Existing [decision 0015](../../../docs/decisions/0015-teacher-only-shared-image-preparation.md) keeps Tasks 1–3 teacher-only. A future external run needs a documented contract extension. |
| [Local Fashion Product Images provenance](../../../docs/data-provenance/fashion-product-images.md) | Same-ID external views are available locally. | This task checked IDs and six development image previews, not external catalogue labels. Filename overlap is not a complete pixel or family identity proof. |
| [iMaterialist author repository](https://github.com/visipedia/imat_fashion_comp) | 1,012,947 training images, 228 attribute labels, Wish-hosted URLs and released annotation links. | No dataset licence was visible in the README. [Competition rules](https://www.kaggle.com/competitions/imaterialist-challenge-fashion-2018/rules) did not yield readable rule text. Reuse permission and live URL availability remain unverified. |
| [iMaterialist author label map](https://raw.githubusercontent.com/visipedia/imat_fashion_comp/master/iMat_fashion_2018_label_map_228.csv) | IDs 122, 36 and 71 distinguish party, casual and formal dresses; IDs 3–6 identify athletic garment categories. | These are restricted garment categories, not a direct mapping to all nine teacher occasions. A pilot should retain the original auxiliary labels. |
| [ABO official release](https://amazon-berkeley-objects.s3.amazonaws.com/index.html) | 147,702 products, 398,212 catalogue images; listings include product names and descriptive fields. Listings archive is about 83 MB; small-image archive is about 3 GB. | Official page and its [licence file](https://amazon-berkeley-objects.s3.amazonaws.com/LICENSE-CC-BY-4.0.txt) say CC BY 4.0. An [AWS listing](https://aws.amazon.com/marketplace/pp/prodview-ygocdgcstr7v2) uses a noncommercial label. Preserve the exact downloaded release and accompanying terms rather than merging these descriptions. No native nine-class occasion target was verified. |
| [Fashionpedia author repository](https://github.com/cvdfoundation/fashionpedia) | 27 main categories, 19 garment parts and 294 attributes, with segmentation masks. | [Official licence page](https://fashionpedia.github.io/home/data_license.html): annotations are CC BY 4.0; images have source-specific terms. Do not describe every image as uniformly CC BY. Suitable for auxiliary attributes/masks, not direct Usage supervision. |
| [DeepFashion2 author repository](https://github.com/switchablenorms/DeepFashion2) | 491,895 images, 13 clothing categories, identity/landmark information and shop/customer views. | Download requires an access form/password. No blanket reuse licence was verified here. Identity/style annotations are not occasion labels. |
| [SFS author deposit](https://zenodo.org/records/833051) | 293,105 street-fashion posts with outfit tags; about 47.5 MB metadata and 27.4 GB image parts. | The primary text extraction did not resolve the licence. README retrieval was unavailable. Do not infer permission from an open download alone. Tags apply to outfits, creating a mismatch with isolated teacher products. |
| [Fashion32 original paper](https://arxiv.org/html/1912.06227v1) | Outfit-level occasion labels include party, travel, sports, business and home; the paper originally described future release. | A later [FashionRec dataset card](https://huggingface.co/datasets/Anony100/FashionRec) names Fashion32 among its inputs. Thus “never released anywhere” would be too strong. The derivative's raw occasion provenance and licence remain unverified. |
| [FashionKE author repository](https://github.com/mysbupt/FashionKE) | Repository states it cannot release the data because of Instagram user authorization. | Not an available training source for this project. Its [paper](https://arxiv.org/html/1908.08985v1) uses context-rich occasion reasoning; it is not a directly comparable 60×80 product-only benchmark. |
| [GarmentIQ publisher page](https://www.kaggle.com/datasets/lygitdata/garmentiq-classification-set-nordstrom-and-myntra) | 23,266 images from Myntra/Nordstrom, nine garment types. | Page lists CC BY-NC-SA 4.0. Garment type is not occasion, and the Myntra source creates overlap risk requiring an actual duplicate check. |
| [Second-hand clothing author deposit](https://zenodo.org/records/12518734) | 31,997 garments, multiple views and garment properties. | CC BY 4.0 on the deposit. Its usage field concerns garment reuse/repair/recycling outcomes, so matching the column name would create wrong targets. |
| [Kang et al., Decoupling Representation and Classifier](https://arxiv.org/abs/1910.09217) | Studies separating visual representation learning from class rebalancing in long-tailed recognition. | Motivation for a two-stage scratch experiment; different datasets and evaluation cannot supply an expected gain here. |
| [Menon et al., Long-tail learning via logit adjustment](https://arxiv.org/abs/2007.07314) | Studies prior-based logit adjustment during training or inference and balanced classification error. | Balanced error is not macro-F1. The fixed exponent check here is sensitivity analysis, not a reproduction of the paper's full method. |
| [Ren et al., Balanced Meta-Softmax](https://proceedings.neurips.cc/paper/2020/hash/2ba61cc3a8f44143e1f2f13b2b729ab3-Abstract.html) | Provides another loss-level approach to long-tailed recognition. | Worth considering after the simpler two-stage test; adding it simultaneously would obscure which change mattered. |

All model-score claims in the report come from local run artifacts and the accompanying scripts, not published fashion benchmark scores. External licence uncertainty is a source-feasibility finding, not a request for human image annotation.
