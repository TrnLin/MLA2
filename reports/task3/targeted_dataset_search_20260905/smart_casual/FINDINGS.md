# Smart Casual dataset search — 2026-09-05

No ready, verified, independent real-product dataset with the teacher's exact `usage=Smart Casual` label was established. Two new sources are worth keeping: **FashionStylist** has useful existing item descriptions but no directly released image archive; **Garments2Look** has native Smart Casual outfit descriptions, but its labels belong to outfits and its look images are synthetic. Neither can simply be appended as teacher-labelled products.

No training, teacher-label inspection, split changes, annotation work, or commits were done. No candidate has passed overlap checks against teacher data. Image quality was not assessed: no image samples were downloaded or rendered. Metadata findings below do not imply visual quality.

## 1. FashionStylist — small mixed-provenance lead, access blocked

[Official release and schema](https://github.com/recsys-benchmark/FashionStylist), [English male labels](https://github.com/recsys-benchmark/FashionStylist/blob/main/Dataset/Male/label_en.csv), [Chinese male labels](https://github.com/recsys-benchmark/FashionStylist/blob/main/Dataset/Male/label(p1-1390).csv), [paper release protocol](https://arxiv.org/html/2604.09249v1), [dataset licence](https://github.com/recsys-benchmark/FashionStylist/blob/main/LICENSE).

Downloaded and counted all six English CSVs. Actual totals match advertised totals: 1,000 outfits and 4,637 item rows (Female 500/2,406; Male 300/1,390; Child 200/841). Items have native `style` text, category and other attributes. The paper describes a nine-person expert annotation team; real Taobao/Dewu products, with some AI-assisted image restoration. The release provides source URLs and annotations. The repository licence is **CC BY-NC 4.0**; this is distinct from the paper's licence and does not make source retailer images owned by the authors.

There are **48 male item rows containing the literal phrase `smart casual`**, but **zero whole-cell labels equal to `Smart Casual`**. The all-source unique product count is **unknown**: 29 rows have an explicit URL `id` parameter, representing **23 distinct nonempty IDs**; 18 rows have unresolved shortlinks; one row has the non-URL marker `AI生成` (AI-generated). There are 47 actual URL rows and 44 distinct actual URLs. The earlier 24-product figure was wrong: it counted the empty ID value and ignored unresolved sources. Female and Child have zero phrase matches. The matched CSV preserves every native English phrase, Chinese phrase and source value. None of the ten matched phrase forms expresses negation.

The AI-generated marker belongs to male item `p808`, `smart casual leather handbag` / `轻商务皮革手提包`. The paper describes AI-assisted restoration for some recoverable images; this item-level marker does not establish whether p808 was restored or generated from scratch. Its image provenance is unresolved and it must not be called a verified real-product example.

Exact matched phrase counts: `smart casual trousers` 16; `trendy smart casual shoes` 9; `smart casual shoes` 7; `smart casual jacket` 5; `smart casual glossy loafers` 3; `smart casual top` 3; `smart casual leather handbag` 2; `smart casual leather tie` 1; `trendy smart casual top` 1; `smart casual bag` 1. Categories: shoes 19, bottom 16, outerwear 5, inner_top 4, bag 3, accessory 1. No watch coverage among these matches.

Translation matters: the Chinese source mixes `轻正式休闲` (roughly light-formal casual), `轻商务` (light business) and `潮酷轻正式` (trendy light-formal). These are existing English release translations, not a new annotation made here. Treat them as a native style-text auxiliary target, not proof of teacher Usage equivalence.

**Access result:** the recursive repository tree has only three example JPGs and a logo, no dataset image archive. The benchmark loader expects local `photos/` folders. Three distinct explicit-ID product links returned HTTP 200 but only small login-related HTML pages with zero image tags. No download-ready count is established; these probes do not test the 18 unresolved shortlinks. No sign-in bypass attempted. Next step: only reconsider if an official accessible image release appears or the images are already lawfully available locally; do not budget a training experiment around these URLs yet.

Outfit `occasion` is separate. Slash-separated token counts verified: Travel 148 (Female 20, Male 86, Child 42); Home 208 (100, 108, 0); Business 108 (all Female). A child outfit can have several occasions, so these counts overlap. Do not copy outfit occasion to every item, and do not map Business to Smart Casual.

## 2. Garments2Look — useful outfit-style auxiliary source, synthetic mismatch

[Official release](https://huggingface.co/datasets/ArtmeScienceLab/Garments2Look), [official code](https://github.com/ArtmeScienceLab/Garments2Look), [Polyvore outfit JSON](https://huggingface.co/datasets/ArtmeScienceLab/Garments2Look/blob/main/polyvore_outfit_v1.0_2512.json), [provenance supplement](https://openaccess.thecvf.com/content/CVPR2026/supplemental/Hu_Garments2Look_A_Multi-Reference_CVPR_2026_supplemental.pdf).

Advertised: 80K many-garment-to-look pairs, with real product reference images, synthetic look images, and expert-reviewed Gemini-2.5-Flash text. Card licence: Apache-2.0; original retail/Polyvore image rights remain a separate consideration. The released loader and metadata genuinely connect outfit IDs to garment IDs and `outfit_info.style`/`occasion`.

Actual bounded check: HTTP 206 bytes 0–99,999 of the 31,158,678-byte Polyvore outfit JSON yielded **57 complete prefix records**. Two contain Smart Casual in style: outfit `51315322`, `Smart Casual Chic`, occasion `Daily Wear, Smart Casual Office, Brunch`; outfit `52962944`, `Vibrant Smart Casual`, occasion `Daily Wear`. One has `Business Casual`; one `Cozy-Chic Loungewear`. These are sample counts, not whole-dataset frequencies. See saved prefix and parsed records in `evidence.json`.

Images are downloadable in large archives: Polyvore item images about 3.38 GB, look images about 25.46 GB. MyTheresa image parts are far larger. No bulk download was attempted. Next step: consider only a separate outfit-style auxiliary task after a bounded item-image access and duplicate audit. A Smart Casual outfit's necklace or bag is not independently labelled Smart Casual. This cannot directly fix the teacher's watch-heavy single-item class.

## 3. Fashion LookMatch Synthetic — exact tag, weak evidence for real teacher images

[Creator's dataset card](https://huggingface.co/datasets/orianrivlin/fashion-lookmatch-dataset), [actual first-row schema](https://datasets-server.huggingface.co/first-rows?dataset=orianrivlin/fashion-lookmatch-dataset&config=default&split=train).

Advertises 1,000 SDXL-generated product images, MIT card licence, 1024×1024, with a native multi-label `style_tags` field. Verified first 100 rows: `smart_casual` appears 20 times, `formal` 23, `casual` 20. Labels come from the image-generation prompt schema, not independent human assessment. Samples can carry Smart Casual and Casual/Formal together. This is not a real-image source or a ground-truth boundary test; generated images inherit a pretrained generator's visual knowledge. Exclude from the main recommendation. No visual quality claim and no image download.

## Other sources checked and exclusions

- **Fashion32 / FashionRec:** [Fashion32 primary page](http://www.larry-lai.com/fashion.html), [FashionRec released metadata guide](https://huggingface.co/datasets/Anony100/FashionRec/blob/main/meta/README.md). The companion Travel audit verified 103,283 outfit rows, including 13,981 Fashion32 records; occasion counts include `职场` (workplace) 2,759, `聚会` (gathering/party) 1,211, `约会` (date) 4,706 and `旅行` (travel) 1,724. These labels belong to outfits. Its released construction code copies outfit occasion into item records; that is not independent item annotation. Do not map workplace to Smart Casual. Generated descriptions and dialogue are mixed with source annotations. Do not treat repackagings as independent datasets. See `../travel/fashionrec_metadata_audit.json`; the redundant parquet downloaded here was removed after the companion audit succeeded. Licence must be resolved across source datasets before reuse.
- **CVPR 2022 “How Good Is Aesthetic Ability of a Fashion Model?”:** [primary supplement](https://openaccess.thecvf.com/content/CVPR2022/supplemental/Zou_How_Good_Is_CVPR_2022_supplemental.pdf). Search-accessible primary text lists Smart Casual questions 59–61 within a 100-question aesthetic/compatibility assessment. This is not evidence of a large labelled product-image corpus. Direct PDF access returned HTTP 403 during this check, so no render or full release inspection was possible. No dataset-size or licence claim; do not shortlist on those three question numbers.
- **DeepFashion Category/Attribute:** [official release and terms](https://mmlab.ie.cuhk.edu.hk/projects/DeepFashion.html), [primary label supplement](https://liuziwei7.github.io/papers/deepfashion_supp.pdf). Real clothing images with category, attribute and landmark supervision; attributes were automatically derived then screened by humans. The official page claims 800K across multiple benchmarks and 1,000 attributes; these are not counts of Smart Casual products. Exact native Smart Casual was not verified. Noncommercial research only, no redistribution; Category/Attribute images do not need the password required by some other benchmarks. Exclude as a direct usage-label fix.
- **IQON3000:** [author release](https://github.com/hanxjing/GP-BPR). Public metadata link and user/outfit/item structure, plus matching tuples `UserID|TopID|PositiveBottomID|NegativeBottomID`. No native Smart Casual label/schema was verified; compatibility is not occasion classification. No image or metadata archive downloaded, licence unresolved. Exclude as direct supervision.
- **Hipster Wars:** [author paper](https://www.cs.unc.edu/~hadi/publications/papers/kiapourECCV14hipster.pdf). Advertised 1,893 full-body images with five styles: Bohemian, Goth, Hipster, Pinup, Preppy; crowd comparison ratings. No Smart Casual/Casual/Formal/Party labels. Different unit and taxonomy; Preppy is not Smart Casual. Current image access and licence not established, no download.
- **Dress Code:** [official dataset and access rules](https://github.com/aimagelab/dress-code). Advertised 53,792 garments/107,584 paired images, three garment categories plus pose/parsing data. Despite the name, it is a virtual try-on dataset, not a dress-code/occasion-label release. Institutional-email request and signed agreement required; no request was sent. Exclude as direct usage supervision.

## Decision

Keep FashionStylist as a **small, currently access-blocked lead** and Garments2Look as an **optional separate outfit-style source**. Neither is ready for teacher usage training. Keep native labels separate, deduplicate by product and image identity, and check all teacher roles for overlap before any future import. Preserve the canonical split and never use teacher evaluation labels to choose or filter external examples.

Evidence: `evidence.json`, the six English FashionStylist CSVs, Chinese label CSVs, `fashionstylist_smart_casual_matches.csv`, `garments2look_polyvore_prefix.txt`, the released G2L loader, and the LookMatch first-row JSON. The metadata-only audit script runs with `./.venv/bin/python reports/task3/targeted_dataset_search_20260905/smart_casual/inspect_metadata.py`.
