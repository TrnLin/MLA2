Fashion Intelligence workflow

One teacher-only shared data contract. Five development folds. One sealed holdout. Task choices stay with their owners.

What the assignment rewards

The mark comes from comparison breadth, justified choices, honest failure analysis, an ultimate judgement, and a clear report. Accuracy alone is not a marking item. Submitted models must be trained from scratch. Pretrained systems may appear only as comparison benchmarks.

Shared preparation

Notebook 01 reads only data/raw/teacher. It discovers files, hashes raw image bytes before decode, checks exact CSV/image ID sets, audits duplicates and families, validates folds, and writes development-only evidence. Full mode rebuilds in a child process, so protected labels never enter the notebook kernel.

No model is trained. No metric, transform, image size, sampler, loss, normalization, or retrieval rule is selected.

Task owner choices

Each owner chooses one fixed fold or all five, defines hypotheses and baselines, compares preprocessing and candidate models, freezes a metric before final comparisons, logs every run to results/runs.csv, and analyses errors, robustness, and cost.

Task 4 additionally owns arbitrary query sizes, one or more image sizes, optional external images, query/gallery isolation, relevance, K, index construction, and ranking evaluation. These are open decisions, not shared preparation rules.

Final evaluation

Notebook 06 receives frozen run IDs and configurations. It refits on all development, refits final preprocessing there, locks checkpoints, opens holdout once, reports the independent result, and does not tune afterwards. Official prediction data is separate from this internal holdout.
