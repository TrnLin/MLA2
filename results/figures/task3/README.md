# Task 3 figures

## Main report figures

`main_analysis/` contains the charts generated by the main report notebook.
Other files retain dated experiment and failure evidence. See the
[Task 3 evidence index](../../../reports/task3/README.md) for the source tables.

`selected_refit_evaluation/` contains the current final evaluation figures:
Gender MixUp and Usage E8 confusion matrices, the Gender error gallery,
single-refit uncertainty and confidence plots.

`gender_development_model_comparison.png` and
`usage_development_model_comparison.png` show all development model variants,
with panels for the saved folds and scoring labels. Prediction diagnostics are
marked separately. The matching CSVs retain each plotted value and its source.
Notebook 06 and the report use these same charts. Rebuild without training:

```bash
PYTHONPATH=src ./.venv/bin/python -m fashion.task3_comparison_figures
```
