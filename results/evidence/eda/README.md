# EDA evidence

The official `notebooks/00_eda.ipynb` writes a scoped JSON summary and flat CSV
evidence here during **Run All**.
The tables cover partitions, provisional review/sign-off status, full official
outputs, the supported primary-metric slice, train/validation coverage, hierarchy
and season-family basis, paired high-resolution coverage, transforms, and the
product-level Task 4 contract. Raw metadata uses an ID-only digest. They do not
aggregate protected holdout or quarantine target outcomes. The former
`data_reconciliation.json` file was removed because it was stale and outside the
official evidence graph.
